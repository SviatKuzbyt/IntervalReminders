# IntervalReminders
An application for interval repetition of learning foreign words. When learning new words, it is recommended to repeat them at a certain interval to memorize them well. The app will determine the intervals of word repetition and notify you at the right time.
## Features

#### Interface:
- **Repeat today.** List of words/cards you need to review today
- **All cards.** List of all words/cards saved on your device
- **New card.** Text box for creating new words/cards

#### Functionality: 
- Add, delete, and view all cards
- View and "mark as repeated" cards that need to be repeated
- Notify you when cards are repeated
